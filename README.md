# 智能待办清单

生活效率工具箱 - 智能待办清单应用

## 功能特性

- ✅ 创建、编辑、删除任务
- ✅ 标记任务完成/未完成
- ✅ 任务分类（工作/学习/生活/其他）
- ✅ 优先级管理（高/中/低）
- ✅ 截止日期和提醒时间
- ✅ 5种任务状态：待处理、进行中、即将到期、已过期、已完成
- ✅ 筛选和排序功能
- ✅ 统计数据展示
- ✅ 本地存储持久化
- ✅ 响应式布局
- ✅ XSS安全防护
- ✅ 输入验证

## 技术栈

- HTML5
- TailwindCSS 3
- Font Awesome 4.7
- Vanilla JavaScript
- LocalStorage

## 在线访问

## 启用 GitHub Pages（如果尚未启用）

1. 进入仓库 Settings
2. 找到 Pages 选项
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main` 分支，`/ (root)` 目录
5. 点击 Save
6. 等待几分钟后即可访问

## 本地运行

直接打开 `index.html` 文件即可使用，无需服务器。
